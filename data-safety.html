01

Data Safety Summary

Google Play's Data Safety section requires developers to disclose what user data their app collects and shares. Because BillWise Pakistan is built on an offline-first architecture, user data stays on the user's phone.

Question Required Answer Developer Context
Does your app collect or share any of the required user data types? No (or "No data collected off-device") All utility bill numbers, accounts, and reminders are stored exclusively on-device in `AsyncStorage`. No data is transferred off the device to proprietary servers.
Is all user data collected by your app encrypted in transit? Yes (or N/A) If public duplicate bill lookups are performed over HTTPS, all network requests are encrypted via TLS/SSL.
Do you provide a way for users to request that their data is deleted? Yes Users can delete accounts inside the app or clear app storage in Android settings.
02

Data Collection Disclosure

According to Google Play policy, data that is stored only locally on the device and never transmitted off the device is not considered "collected" for the purposes of the Data Safety section.

Google Play Policy Definition Note

"Data collected by your app means data transmitted off the user's device." Because BillWise Pakistan does not transmit bill numbers, personal identifiers, or amounts to any server, it does not engage in remote data collection.

03

Data Sharing Disclosure

No Data Shared with Third Parties: BillWise Pakistan does not sell, lease, transfer, or disclose user utility information to advertising networks, data brokers, or commercial marketing entities.

04

Security Practices

  • Data Encrypted in Transit: Any outgoing communication (e.g. duplicate bill queries via official DISCO portals) uses secure HTTPS (TLS 1.2+).
  • Sandbox Isolation: Application utilizes the operating system's internal sandbox storage preventing unauthorized inter-app snooping.
  • Data Deletion Mechanism: Full data wipe is supported via standard OS storage wipe and in-app account deletion.
